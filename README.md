# Tic-Tac-Toe Game in Python

A terminal-based Tic-Tac-Toe game built using Python.

## Features

- Two-player gameplay
- Displays the game board in the terminal
- Players select moves using row and column numbers
- Checks for invalid and already occupied positions
- Detects winners and draws

## Requirements

- Python 3 installed

## How to Run

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run the following command:

```bash
python main.py
```
